# 经方问询助手 / 经方诊室

中医小诊所用的理论 Skill 和诊所问诊页面。

**不是自动医生。** 方证、煎煮、检验解读、收费和 AI 医生，都只给执业中医师作草稿。

## 安装与使用

详细步骤见 [references/install-guide.md](references/install-guide.md)。

日常只记这三步：

1. 打开经方诊室，确认执业边界，右上角选医师或助手。
2. 看诊填写患者和症状，生成方证草稿；需要时用法库、检验、收费。
3. 右下角 AI 医生可打字、语音、拍照。要完全放在诊所电脑，方库页勾选本机 Ollama。

## 仓库里有什么
