# 诊所版前端问诊页面原型说明

**适用场景**：中医小诊所诊间平板 / 微信小程序 / 桌面Web  
**目标用户**：执业中医师、医师助理、前台助手  
**核心原则**：辅助采集与理论参考，绝不替代面诊决策

---

## 一、整体信息架构

```
首页
├── 新建问诊
├── 历史问诊记录
├── 知识检索（快速查概念/方证）
├── 个人设置（角色切换：医师/助手）
└── 帮助与边界说明
```

---

## 二、核心页面原型

### 1. 新建问诊页（主流程）

**顶部**：
- 患者临时编号 / 姓名（可选脱敏）
- 医师姓名 + 当前角色标识（医师/助手）
- 「保存草稿」按钮

**主体分区（可折叠）**：

| 分区 | 字段 | 说明 |
|------|------|------|
| 主诉 | 多行文本 | 患者自述核心不适 |
| 现病史 | 多行文本 + 时间选择 | 起病时间、演变 |
| 寒热 | 单选+补充 | 喜冷/喜热/手足冷热/恶寒发热 |
| 二便 | 结构化 | 大便次数性状、小便颜色次数 |
| 睡眠 | 结构化 | 入睡难易、夜醒时辰（1-3点等） |
| 口渴饮水 | 单选 | 口渴喜冷/喜热/不渴 |
| 舌脉 | 医师填写区 | 舌质舌苔、脉象（助手只读） |
| 既往史用药 | 多行文本 | 既往疾病、正在服用药物 |
| 其他补充 | 多行文本 | 情绪、饮食、季节等 |

**底部操作**：
- 「生成理论参考」主按钮（调用Agent）
- 「清空」与「保存并结束」

### 2. Agent回复展示区

回复固定结构（与System Prompt一致）：

1. **问题理解**
2. **相关理论框架**（八纲/六经/脏腑）
3. **课程观点摘要**（带来源课次）
4. **建议进一步确认的问题**
5. **免责声明**（红色加粗，不可关闭）

**交互**：
- 每条回复可「复制」或「加入病历备注」
- 高风险内容自动标黄 + 禁止复制处方格式
- 支持追问（多轮对话保留上下文）

### 3. 知识快速检索页

- 搜索框（支持概念、方证名、症状关键词）
- 结果卡片：标题 + 摘要 + 来源 + 权限标识
- 点击进入详情（restricted内容对助手仅显示摘要）

### 4. 历史记录页

- 按日期/患者编号列表
- 支持筛选（本人/全部）
- 点击可查看完整对话 + 导出PDF（仅理论参考，无处方）

---

## 三、角色差异化界面

| 功能 | 医师账号 | 助手账号 |
|------|----------|----------|
| 查看restricted理论摘要 | 完整 | 仅摘要+来源 |
| 填写舌脉 | 可写 | 只读 |
| 导出完整对话 | 可以 | 需医师确认 |
| 修改System Prompt | 不可以 | 不可以 |
| 查看审计日志 | 本诊室 | 仅自己操作记录 |

---

## 四、关键交互细节

1. **强制免责声明**：每次Agent回复底部固定显示，且首次进入系统弹窗确认。
2. **急症拦截**：检测到「胸痛、呼吸困难、昏迷、大出血」等关键词，立即弹出红色提示「请立即就医或拨打急救」，并锁定继续理论讨论。
3. **空状态引导**：新建问诊时显示「建议先填写主诉与寒热二便，再生成参考」。
4. **移动端适配**：诊间平板优先，按钮足够大，支持横屏。
5. **离线提示**：网络异常时显示「当前无法连接知识库，请检查网络或联系管理员」。

---

## 五、技术实现建议（低成本）

- 前端：Uni-app 或 Taro（一套代码多端）
- 或直接使用 Dify / FastGPT 自带 WebApp + 自定义页面
- 状态管理：问诊草稿本地缓存（防止误关）
- 权限：JWT + 角色字段，前端根据角色隐藏按钮

---

## 六、验收标准

- [ ] 完整走通「新建→填写→生成参考→追问→保存」流程
- [ ] 助手账号无法看到完整restricted内容
- [ ] 急症关键词触发红色拦截
- [ ] 每条回复均有免责声明
- [ ] 历史记录可按权限正确过滤
