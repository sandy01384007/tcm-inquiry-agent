# 经方问询助手 — 诊所培训手册大纲

**适用对象**：诊所全体医师、助理、前台  
**培训目标**：正确使用Agent、严格守住医疗边界、提升问诊效率  
**建议时长**：初次培训 2 小时 + 上线后 1 周跟进

---

## 一、培训目标与原则

1. 理解Agent的定位：**理论检索与问诊辅助工具**，不是自动开方系统
2. 掌握标准使用流程
3. 牢记绝对禁止事项
4. 学会区分医师与助手的权限差异
5. 知道如何反馈问题与异常

**核心原则口诀**：  
「能查理论，不给处方；能采信息，不做诊断；有疑问，转医师。」

---

## 二、培训议程建议

| 时段 | 内容 | 形式 | 时长 |
|------|------|------|------|
| 第1段 | 产品定位与边界红线 | 讲解 + 案例 | 30分钟 |
| 第2段 | 系统操作演示 | 现场操作 | 40分钟 |
| 第3段 | 医师与助手权限差异 | 对比演示 | 20分钟 |
| 第4段 | 常见错误与应急处理 | 案例讨论 | 20分钟 |
| 第5段 | 考核与签字确认 | 测试 + 承诺书 | 10分钟 |

---

## 三、详细培训内容大纲

### 模块1：认识经方问询助手
- 它能做什么（检索八纲、六经、药性、课程观点）
- 它绝对不能做什么（开方、剂量、针刺指导、诊断结论）
- 为什么必须有免责声明
- 与「百度搜方」的本质区别

### 模块2：标准使用流程
1. 登录并确认角色（医师/助手）
2. 新建问诊 / 直接知识检索
3. 填写结构化信息（主诉、寒热、二便、睡眠等）
4. 点击「生成理论参考」
5. 阅读回复结构（理解→框架→课程观点→进一步问题→免责）
6. 追问与保存
7. 结束问诊并归档

### 模块3：权限与界面差异
- 医师可见完整理论摘要
- 助手仅见基础概念与极简摘要
- 舌脉字段仅医师可填写
- 高风险内容对双方均拦截

### 模块4：红线与应急
**绝对红线**：
- 要求Agent开方或写剂量
- 要求穴位操作步骤
- 对急症患者继续理论讨论而不转诊
- 把Agent回复直接当处方给患者

**应急处理**：
- 系统提示急症 → 立即按诊所急救流程处理
- Agent回答异常 → 截图反馈管理员
- 患者要求「按这个方开药」 → 明确告知「这是理论参考，最终由医师决定」

### 模块5：考核要点（通过标准）
- [ ] 能完整走通一次问诊流程
- [ ] 能正确说出至少3条绝对禁止事项
- [ ] 能区分医师与助手看到的内容差异
- [ ] 遇到「给我开个方」能正确拒绝并解释
- [ ] 知道急症关键词出现时该怎么做

## 四、配套材料清单

1. 本培训大纲
2. 快速操作卡片（一页纸，贴诊间）
3. 边界红线海报（醒目位置）
4. 用户承诺书（签字确认已培训）
5. 测试用例集（从 `TCM_Agent_Test_Cases.md` 抽取日常题）
6. 反馈表（问题、建议、异常记录）

---

## 五、上线后跟进计划

| 时间 | 动作 |
|------|------|
| 上线第1天 | 管理员在场支持，收集第一波问题 |
| 上线第3天 | 短会复盘高频问题与卡点 |
| 上线第7天 | 抽查日志，确认无越权与漏拦 |
| 每月 | 更新知识库 + 补充培训（新功能/新案例） |

! 急症关键词出现 → 立即转诊/急救
